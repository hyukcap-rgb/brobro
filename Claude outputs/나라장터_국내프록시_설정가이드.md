# 나라장터 API 접속을 위한 국내(한국) 중계 서버 설정 가이드

## 왜 필요한가

지금 앱은 Railway(미국 캘리포니아 서버)에서 돌아가고 있는데, 나라장터 API(`apis.data.go.kr`)가 해외 서버에서 오는 접속을 막고 있는 것으로 확인됐습니다. 그래서 물품/용역/공사 검색이 전부 타임아웃으로 실패하고 있습니다.

해결 방법은 나라장터로 나가는 요청만 **한국에 있는 작은 서버를 한 번 거쳐서** 보내는 것입니다. 앱 코드에는 이미 이런 중계(프록시) 기능이 내장되어 있어서, 한국 서버 하나만 준비되면 제가 나머지(연결 설정)를 진행할 수 있습니다.

준비할 것: 네이버클라우드플랫폼(NCP) 계정 + 마이크로 서버 1대 (1년 무료).

---

## 1단계 — 네이버클라우드플랫폼 가입

1. [naver cloud platform](https://www.ncloud.com) 접속 → 우측 상단 **회원가입**.
2. 개인 회원으로 가입하고, 로그인합니다.
3. 콘솔(Console) 진입 후 **결제 정보(카드) 등록**을 합니다. (이 시점부터 마이크로 서버 무료 기간 1년이 시작됩니다. 마이크로 서버 자체는 1년간 과금되지 않지만, 카드 등록은 본인확인 절차상 필요합니다.)

> 참고: 1년 무료 기간이 지나면 자동으로 과금되니, 캘린더 등에 "N년 뒤 이 서버 확인" 알림을 하나 남겨두시는 걸 추천합니다.

## 2단계 — 마이크로 서버 생성

1. 콘솔 좌측 메뉴에서 **Compute → Server** 로 이동 → **서버 생성**.
2. 서버 이미지: **Ubuntu Server (기본 제공 버전, 예: 22.04 이상)** 선택.
3. 서버 타입: **Micro** 등급 선택 (가장 작은 사양 — 이 프록시 용도로는 충분합니다).
4. 스토리지: 기본값 그대로 진행.
5. **인증키 생성 및 저장** 단계에서 반드시 `.pem` 키 파일을 다운로드해 안전한 곳에 보관하세요. (분실 시 서버 접속이 불가능해집니다.)
6. 서버 생성 완료까지 몇 분 기다립니다.

## 3단계 — 공인 IP 연결

1. **Network → Public IP** 메뉴로 이동 → **공인 IP 신청**.
2. 방금 만든 서버에 연결(적용)합니다.
3. 화면에 표시된 공인 IP 주소를 메모해 둡니다. (예: `123.45.67.89`) — 나중에 Railway 설정에 이 주소가 필요합니다.

## 4단계 — 방화벽(ACG) 포트 열기

1. **Network → ACG** 메뉴로 이동 → 서버에 연결된 ACG 선택 → **접근 규칙 설정**.
2. 인바운드 규칙에 아래 2개를 추가합니다:
   - TCP `22` (SSH 접속용) — 가능하면 접근 소스를 본인 현재 IP로 제한 (모르면 일단 `0.0.0.0/0`으로 열어두고 나중에 제한해도 됩니다)
   - TCP `3128` (프록시용 포트) — 소스 `0.0.0.0/0` (Railway가 여기로 접속해야 하므로 열어둬야 합니다. 대신 5단계에서 비밀번호 인증을 걸어 아무나 못 쓰게 막습니다.)

## 5단계 — 서버에 프록시 설치

1. 터미널(Mac/Linux) 또는 WSL(Windows)에서 서버에 접속합니다:
   ```bash
   chmod 400 다운로드한키.pem
   ssh -i 다운로드한키.pem root@서버의_공인IP
   ```
2. 접속되면 아래 명령을 순서대로 실행해 `tinyproxy`(가볍고 인증 지원되는 프록시 프로그램)를 설치합니다:
   ```bash
   apt update && apt install -y tinyproxy apache2-utils
   ```
3. 접속 비밀번호를 설정합니다 (원하는 아이디/비밀번호로 바꿔서 실행):
   ```bash
   echo "railway:여기에원하는비밀번호입력" | tee /etc/tinyproxy/tinyproxy-users
   ```
4. 설정 파일을 엽니다:
   ```bash
   nano /etc/tinyproxy/tinyproxy.conf
   ```
   아래 항목들을 찾아서 다음과 같이 수정/추가합니다 (이미 있으면 값만 바꾸세요):
   ```
   Port 3128
   Allow 0.0.0.0/0
   BasicAuth railway 여기에원하는비밀번호입력
   ```
   저장 후 종료: `Ctrl+O` → `Enter` → `Ctrl+X`
5. 프록시를 재시작하고 자동 시작 등록:
   ```bash
   systemctl restart tinyproxy
   systemctl enable tinyproxy
   ```
6. 정상 작동 확인 (서버 안에서):
   ```bash
   curl -v -x http://railway:여기에원하는비밀번호입력@localhost:3128 https://www.data.go.kr
   ```
   HTML 응답이 나오면 성공입니다.

## 6단계 — 완료 후 저에게 알려주세요

여기까지 하시면, 아래 3가지 정보를 저에게 알려주세요. 그러면 제가 Railway 환경변수(`HTTPS_PROXY`)를 설정하고 실제로 나라장터 검색이 되는지 재테스트까지 진행하겠습니다.

- 서버의 공인 IP 주소
- 프록시 아이디 (예: `railway`)
- 프록시 비밀번호

(이 정보는 Railway 서버 환경변수에만 저장되고 코드에는 들어가지 않습니다. 비밀번호는 채팅에 남기고 싶지 않으시면, 저에게 "설정했다"고만 알려주시고 실제 값은 Railway 콘솔에 직접 입력하셔도 됩니다 — 그 경우 변수 이름과 형식만 알려드리겠습니다.)

---

## 참고 — 나중에 비용이 걱정되면

- 마이크로 서버는 가입 후 1년간 무료입니다. 1년 뒤에도 계속 쓰려면 월 소액(가장 저렴한 등급) 요금이 발생합니다.
- 이 프록시는 트래픽이 매우 적기 때문에(하루 한 번, 짧은 API 호출 몇 건) 성능 걱정은 하지 않으셔도 됩니다.
- 더 이상 필요 없어지면 NCP 콘솔에서 서버를 삭제(반납)하면 과금이 멈춥니다.
